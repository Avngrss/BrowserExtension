# Bug Capture Assistant

A Chrome extension for manual and exploratory testing. You test a page as usual. When something looks wrong, the useful context is already captured, and you can copy a bug ticket instead of writing one from memory.

It watches one tab and records what you did, what the page showed, what failed in the console, and which requests failed. Related evidence becomes one potential bug, with a screenshot when one was taken. **Create ticket** turns that bug into a draft you can paste into a tracker.

Everything stays on your machine. There is no account, no cloud, and no model call in this version.

How to install and try it: [docs/demo-ru.md](./docs/demo-ru.md).
